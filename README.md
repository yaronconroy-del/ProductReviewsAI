# מזכירה – משימות מהטלפון לפרוייקטים במחשב

רושמים משימה בסשן "פרוייקט סנכרון משימות" באפליקציית Claude בטלפון → המזכירה שואלת לאיזה
פרוייקט במחשב היא שייכת → שומרת אותה כאן (`tasks.json`). פעם בשעה, כל עוד יש משימות פתוחות,
היא בודקת אם המחשב דלוק (סשן Remote Control מחובר). ברגע שכן – שולחת כל משימה לסשן של
הפרוייקט שלה במחשב, שמתחיל לעבוד עליה מיד, ומסמנת אותה כ"הועברה".

הנוהל המלא: `CLAUDE.md`.
